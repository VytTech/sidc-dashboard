    Projects

    All active projects. Click a row for the position breakdown and the 8-week staffing plan. Short / spare = people booked minus the project manager’s staffing plan this week (red = fewer than planned in at least one job). This is not a request for new people – see “Additional manpower requests”.

    Staffing outlook

    Compared with the project manager’s staffing plan in Ragic, not with requests for new people. Red = fewer people than planned (sum over all jobs), green = every job staffed as planned (number = more than planned). Hover a cell for the positions. Only projects with a staffing plan in Ragic are shown.

    Workforce by position

    Balance by position · this week

    Sum over all planned projects. Negative = positions still to be filled.

    Additional manpower requests

    Requests from the last 4 weeks and upcoming weeks. The request is only the instruction – every selected person is checked in Human Rotation, because rotation can be changed by hand. Reserved = selected and still planned for this project in rotation · Confirmed = arrival confirmed · Working = already on site · Still needed = requested minus reserved · not in rotation = selected people that Human Rotation does not (yet) have on this project – other project, no project or missing. Click a row to see who.

    Management mode

    Labour cost figures are only shown with the management password. They stay visible in this browser tab until you close it or press “Lock”.

    Workers

    Workers are shown by position and a fixed code instead of the name – click the code to open the worker’s card in Ragic (Ragic login required). Alerts: no timesheet = on site but nothing booked in the last completed week (yards without Ragic timesheets are skipped) · other location = hours booked at a different yard than the project in HR · >12 h days (last 4 weeks) · >60 h weeks and avg >48 h/week (last 16 weeks).

    Missing positions

    Numbers compare people booked on the project with the project manager’s staffing plan in Ragic – they are not requests for new people. Red = fewer than planned, green = more than planned, ✓ = as planned. Hover a number to see the planned count.
